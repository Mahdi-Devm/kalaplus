# KalaPlus Architecture

This file contains the stable architectural knowledge of KalaPlus.

## Repository

KalaPlus is a monorepo.

## Applications

### Web

Location:

`apps/web`

Technology:

- Next.js
- React
- TypeScript

### Backend

Technology:

- NestJS
- TypeScript

## Data

Current infrastructure includes:

- PostgreSQL
- Redis
- TypeORM

## API

The project uses GraphQL-related infrastructure.

GraphQL Mesh is used between application layers.

## Frontend

The frontend uses:

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui

## Important Rule

Do not assume this document is complete.

When working on architecture-sensitive tasks, inspect the repository and update this document only when explicitly requested.
